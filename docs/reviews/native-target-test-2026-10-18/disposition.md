# Author disposition: native target diagnostic review

Claude Opus 5.5 independently inspected frozen `abadd20`. The [unedited report](claude-report.md), [execution](execution.json), [manifest](input-manifest.json) and [verified trace](verified-execution.json) retain 23 Read/Grep calls, all within the snapshot. All 124 hashes match, with no permission denials. The reviewer executed no tests, commands or hardware and made no edits.

The report finds no high and two medium defects. Later source `c2e86ed` addresses them:

- **M1 — renderer imports retained after return:** after the target/local-resource scope retires, the shared coordinator invokes a final cleanup hook. The actual adapter calls `GlesRenderer::cleanup_texture_cache`, which removes stale weak-keyed imports and bindings. A cleanup error increments the report count, prevents success and clears tested-target metadata. Existing primary failure remains observable. The fixture checks hook ordering, cached-resource retirement and failure reporting. It does not run the real renderer. The initial report overstates that pinned cleanup never runs: `GlesFrame::finish_internal` does call cleanup, but current targets are still alive there and their imports survive. The missing post-retirement cleanup is the accepted defect.
- **M2 — tested topology differed from the plan:** a shared bounded reconciler now emits all known connector routes, detaches unplanned clones from tested CRTCs, disables source CRTCs losing their last connector and clears their non-selected planes. Unrelated routes retain captured values. Taking a primary plane from an unrelated CRTC with surviving connectors fails explicitly. The actual adapter uses this result to build its TEST_ONLY request. Fixtures cover cloned/moved routes, unrelated conflicts and malformed snapshots. Kernel request construction is still unexecuted; no atomic metadata snapshot or reservation is claimed.

Low partial-error drop-order wording is corrected: local DMA-BUF can retire before the framebuffer guard, while GBM storage retires afterward; the framebuffer retains a kernel reference. Implicit modifier false negatives and strict multi-GPU/outputless health are documented. An internal device-ID parse error would stop before printing JSON while still dropping the driver; actual GPU IDs are generated from typed device IDs, so that branch is not reproduced here.

Accepted controls include fixed TEST_ONLY flags, no surface objects, legacy rejection, bounded admission/retries, error/cleanup accounting, exact raw mode and format revalidation, correct framebuffer modifier flags, complete black render before synchronization, explicit blob ownership and final probe ticket checks. These are static source observations plus separately retained author tests, not hardware execution.

Remaining work includes actual adapter/renderer/ioctl/fence/property/destructor fault qualification, real memory accounting, mode fallback, live commit/page-flip/buffer ownership, output publication and safe preview rollback. The review does not certify production readiness or close a phase gate. A frozen follow-up reviews the later changes separately.
