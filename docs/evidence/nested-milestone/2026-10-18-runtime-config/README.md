## Limits

The six cases do not prove arbitrary concurrent-runtime-generation schedules, every held-input/grab combination, in-place file consistency, sustained client frame progress under reload storms, universal latency/RSS, native input/session or full desktop conformance. Layout clone/validation/relayout still runs on dispatch and scales with admitted windows. Off-thread helper/source/binding preparation and one retirement slot are ownership controls, not full scheduling/fairness qualification.

Non-configuration final smoke commands explicitly disable source discovery with `--no-config`; the initial checkpoint predates that test-isolation correction. Neither review nor local tests close phase 6 or certify production readiness.
